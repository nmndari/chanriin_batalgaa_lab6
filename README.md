## Хэсэг A: Category-Partition — Шилжүүлгийн функц

`POST /transfer { "from": ID, "to": ID, "amount": NUM, "currency": CODE }`

### Алдааны давуу эрэмбэ

Нэг хүсэлтэд хэд хэдэн алдаа зэрэг байвал дараах эрэмбээр **эхний** алдааг буцаана гэж тогтоов:

`ERROR_NO_FROM → ERROR_FROZEN → ERROR_NO_TO → ERROR_SAME_ACCOUNT → ERROR_BAD_AMOUNT → ERROR_INSUFFICIENT → ERROR_LIMIT`

**Үндэслэл:** хүсэлтийг боловсруулах байгалийн дарааллаар — эхлээд илгээгч (from), дараа нь хүлээн авагч (to), эцэст нь дүн (amount) — шалгах бөгөөд дүнгийн дотор хөрвүүлэлт шаардахгүй энгийн шалгалт (≤ 0) эхэлж, дараа нь хатуу хязгаар болох үлдэгдэл, хамгийн сүүлд өдрийн лимит шалгагдана.

### Тестийн орчин (fixture)

Төлөөлөх утгуудыг тодорхой болгохын тулд дараах орчныг тогтоов:

| Данс | Төлөв | Валют | Үлдэгдэл | Өдрийн лимит |
|---|---|---|---|---|
| `A001` | идэвхтэй | USD | 1000 | 500 |
| `A002` | идэвхтэй | USD | 200 | 500 |
| `A003` | царцаагдсан | USD | 1000 | 500 |
| `A004` | идэвхтэй | MNT | 3 400 000 | 1 700 000 |
| `X999` | байхгүй | — | — | — |

Ханш (тогтмол): `1 USD = 3400 MNT`, `1 EUR = 1.10 USD`.

**Таамаглал:** "currency данснаас өөр" гэдэг нь **from** дансны валютыг хэлнэ; үлдэгдэл, лимитийг from дансны валютад хөрвүүлсэн дүнгээр шалгана.

### A1 — Сонголт ба төлөөлөх утгууд

#### Параметр: `from`

| Сонголт | Төлөөлөх утга | Хүлээгдэх үр дүн |
|---|---|---|
| Хүчинтэй (байгаа, царцаагдаагүй) | `A001` | дараагийн шалгалт руу |
| Царцаагдсан | `A003` | `ERROR_FROZEN` |
| Байхгүй | `X999` | `ERROR_NO_FROM` |

#### Параметр: `to`

| Сонголт | Төлөөлөх утга (from = `A001`) | Хүлээгдэх үр дүн |
|---|---|---|
| Хүчинтэй, from-оос өөр | `A002` | дараагийн шалгалт руу |
| Байхгүй | `X999` | `ERROR_NO_TO` |
| from-той ижил | `A001` | `ERROR_SAME_ACCOUNT` |
| Царцаагдсан to данс | `A003` | тодорхойлолтод заагаагүй — дүрмээр зөвхөн from царцаагдаагүй байх ёстой тул `201 OK` гэж үзнэ |

#### Параметр: `amount` (from = `A001`, currency = USD, лимит хоосон)

| Сонголт | Төлөөлөх утга | Хүлээгдэх үр дүн |
|---|---|---|
| Сөрөг | `-50` | `ERROR_BAD_AMOUNT` |
| Тэг (хил) | `0` | `ERROR_BAD_AMOUNT` |
| Хамгийн бага эерэг (хил) | `0.01` | `201 OK` |
| Ердийн хүчинтэй | `100` | `201 OK` |
| Лимиттэй яг тэнцүү (хил) | `500` | `201 OK` |
| Лимитээс их, үлдэгдлээс бага | `600` | `ERROR_LIMIT` |
| Үлдэгдэлтэй яг тэнцүү (хил) | `1000` | `ERROR_LIMIT` (үлдэгдэл хүрэлцэх ч лимит 500) |
| Үлдэгдлээс их | `1000.01` | `ERROR_INSUFFICIENT` |

#### Параметр: `currency` (from = `A001`, данс USD)

| Сонголт | Төлөөлөх утга | Хүлээгдэх үр дүн |
|---|---|---|
| Дансны валюттай ижил | `USD`, amount `100` | `201 OK`, хөрвүүлэлтгүй |
| Өөр, хөрвүүлсний дараа хязгаар дотор | `MNT`, amount `340000` (= 100 USD) | `201 OK` |
| Өөр, хөрвүүлсний дараа лимит хэтэрнэ | `EUR`, amount `460` (= 506 USD > 500) | `ERROR_LIMIT` — USD-ээр 460 бол OK байх байсан |
| Өөр, хөрвүүлсний дараа үлдэгдэл хэтэрнэ | `EUR`, amount `910` (= 1001 USD > 1000) | `ERROR_INSUFFICIENT` |
| Үл мэдэгдэх код | `XYZ` | тодорхойлолтод алдааны код байхгүй — тодруулах шаардлагатай (тестээс хасав) |

#### Далд орчны сонголтууд

Хүсэлтэд ирдэггүй ч үр дүнд нөлөөлөх төлөвүүд:

| Орчны сонголт | Төлөөлөх утга (A001, лимит 500 USD) | Нөлөө |
|---|---|---|
| Өдрийн лимит хоосон | өнөөдөр 0 USD шилжүүлсэн | amount `500` → `201 OK` |
| Өдрийн лимит хагас дүүрсэн | өнөөдөр 300 USD шилжүүлсэн | amount `200` → OK, `201` → `ERROR_LIMIT` |
| Өдрийн лимит бүрэн дүүрсэн | өнөөдөр 500 USD шилжүүлсэн | amount `0.01` → `ERROR_LIMIT` |
| from дансны үлдэгдэл 0 | `A001`-ийн үлдэгдэл 0 | amount `0.01` → `ERROR_INSUFFICIENT` |
| Ханшийн хөрвүүлэлт хийгдэх эсэх | from данс USD, currency MNT/EUR | үлдэгдэл/лимитийг хөрвүүлсэн дүнгээр шалгана |
