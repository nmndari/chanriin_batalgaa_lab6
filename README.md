## Хэсэг A: Category-Partition — Шилжүүлгийн функц

`POST /transfer { "from": ID, "to": ID, "amount": NUM, "currency": CODE }`

### Алдааны давуу эрэмбэ

Нэг хүсэлтэд хэд хэдэн алдаа зэрэг байвал дараах эрэмбээр **эхний** алдааг буцаана гэж тогтоов:

`ERROR_NO_FROM → ERROR_FROZEN → ERROR_NO_TO → ERROR_SAME_ACCOUNT → ERROR_BAD_AMOUNT → ERROR_INSUFFICIENT → ERROR_LIMIT`

**Үндэслэл:** хүсэлтийг боловсруулах байгалийн дарааллаар — эхлээд илгээгч (from), дараа нь хүлээн авагч (to), эцэст нь дүн (amount) — шалгах бөгөөд дүнгийн дотор хөрвүүлэлт шаардахгүй энгийн шалгалт (≤ 0) эхэлж, дараа нь хатуу хязгаар болох үлдэгдэл, хамгийн сүүлд өдрийн лимит шалгагдана.

### Тестийн орчин (fixture)

Төлөөлөх утгуудыг тодорхой болгохын тулд дараах орчныг тогтоов:

| Данс | Төлөв | Валют | Үлдэгдэл | Өдрийн лимит |
|---|---|---|---|---|
| `A001` | идэвхтэй | USD | 1000 | 500 |
| `A002` | идэвхтэй | USD | 200 | 500 |
| `A003` | царцаагдсан | USD | 1000 | 500 |
| `A004` | идэвхтэй | MNT | 3 400 000 | 1 700 000 |
| `X999` | байхгүй | — | — | — |

Ханш (тогтмол): `1 USD = 3400 MNT`, `1 EUR = 1.10 USD`.

**Таамаглал:** "currency данснаас өөр" гэдэг нь **from** дансны валютыг хэлнэ; үлдэгдэл, лимитийг from дансны валютад хөрвүүлсэн дүнгээр шалгана.

### A1 — Сонголт ба төлөөлөх утгууд

#### Параметр: `from`

| Сонголт | Төлөөлөх утга | Хүлээгдэх үр дүн |
|---|---|---|
| Хүчинтэй (байгаа, царцаагдаагүй) | `A001` | дараагийн шалгалт руу |
| Царцаагдсан | `A003` | `ERROR_FROZEN` |
| Байхгүй | `X999` | `ERROR_NO_FROM` |

#### Параметр: `to`

| Сонголт | Төлөөлөх утга (from = `A001`) | Хүлээгдэх үр дүн |
|---|---|---|
| Хүчинтэй, from-оос өөр | `A002` | дараагийн шалгалт руу |
| Байхгүй | `X999` | `ERROR_NO_TO` |
| from-той ижил | `A001` | `ERROR_SAME_ACCOUNT` |
| Царцаагдсан to данс | `A003` | тодорхойлолтод заагаагүй — дүрмээр зөвхөн from царцаагдаагүй байх ёстой тул `201 OK` гэж үзнэ |

#### Параметр: `amount` (from = `A001`, currency = USD, лимит хоосон)

| Сонголт | Төлөөлөх утга | Хүлээгдэх үр дүн |
|---|---|---|
| Сөрөг | `-50` | `ERROR_BAD_AMOUNT` |
| Тэг (хил) | `0` | `ERROR_BAD_AMOUNT` |
| Хамгийн бага эерэг (хил) | `0.01` | `201 OK` |
| Ердийн хүчинтэй | `100` | `201 OK` |
| Лимиттэй яг тэнцүү (хил) | `500` | `201 OK` |
| Лимитээс их, үлдэгдлээс бага | `600` | `ERROR_LIMIT` |
| Үлдэгдэлтэй яг тэнцүү (хил) | `1000` | `ERROR_LIMIT` (үлдэгдэл хүрэлцэх ч лимит 500) |
| Үлдэгдлээс их | `1000.01` | `ERROR_INSUFFICIENT` |

#### Параметр: `currency` (from = `A001`, данс USD)

| Сонголт | Төлөөлөх утга | Хүлээгдэх үр дүн |
|---|---|---|
| Дансны валюттай ижил | `USD`, amount `100` | `201 OK`, хөрвүүлэлтгүй |
| Өөр, хөрвүүлсний дараа хязгаар дотор | `MNT`, amount `340000` (= 100 USD) | `201 OK` |
| Өөр, хөрвүүлсний дараа лимит хэтэрнэ | `EUR`, amount `460` (= 506 USD > 500) | `ERROR_LIMIT` — USD-ээр 460 бол OK байх байсан |
| Өөр, хөрвүүлсний дараа үлдэгдэл хэтэрнэ | `EUR`, amount `910` (= 1001 USD > 1000) | `ERROR_INSUFFICIENT` |
| Үл мэдэгдэх код | `XYZ` | тодорхойлолтод алдааны код байхгүй — тодруулах шаардлагатай (тестээс хасав) |

#### Далд орчны сонголтууд

Хүсэлтэд ирдэггүй ч үр дүнд нөлөөлөх төлөвүүд:

| Орчны сонголт | Төлөөлөх утга (A001, лимит 500 USD) | Нөлөө |
|---|---|---|
| Өдрийн лимит хоосон | өнөөдөр 0 USD шилжүүлсэн | amount `500` → `201 OK` |
| Өдрийн лимит хагас дүүрсэн | өнөөдөр 300 USD шилжүүлсэн | amount `200` → OK, `201` → `ERROR_LIMIT` |
| Өдрийн лимит бүрэн дүүрсэн | өнөөдөр 500 USD шилжүүлсэн | amount `0.01` → `ERROR_LIMIT` |
| from дансны үлдэгдэл 0 | `A001`-ийн үлдэгдэл 0 | amount `0.01` → `ERROR_INSUFFICIENT` |
| Ханшийн хөрвүүлэлт хийгдэх эсэх | from данс USD, currency MNT/EUR | үлдэгдэл/лимитийг хөрвүүлсэн дүнгээр шалгана |


### A2 — Хязгаарлалтууд

**Тэмдэглэгээний утга:**
- `[ERROR]` — алдаа буцаадаг утга; давуу эрэмбээр эхний алдаа нь л харагдах тул бусад параметрийн хэвийн утгатай **нэг удаа** тестлэхэд хангалттай.
- `[SINGLE]` — алдаа биш ч онцгой (хил, тодорхойлолтод заагаагүй) утга; бусадтай хослуулах нь шинэ мэдээлэл өгөхгүй тул **нэг удаа** тестлэнэ.
- `[property X]` — X шинж чанарыг тодорхойлно; `[IF X]` — зөвхөн X шинжтэй утгатай хослох үед утга учиртай.

Дүнг (amount) **from дансны валютад хөрвүүлсний дараа** үлдэгдэл `B` болон өдрийн лимитийн үлдэгдэл `L`-тэй харьцуулж ангилав (fixture-д `L < B`).

| Параметр | Сонголт | Төлөөлөх утга | Тэмдэглэгээ | Үндэслэл |
|---|---|---|---|---|
| **from** | Хүчинтэй | `A001` | `[property FROM_OK]` | Цорын ганц амжилттай замд хүргэдэг утга тул бусад параметрийн хэвийн утгуудтай хослоно. |
| | Царцаагдсан | `A003` | `[ERROR]` | Үргэлж `ERROR_FROZEN` буцаана. |
| | Байхгүй | `X999` | `[ERROR]` | Үргэлж `ERROR_NO_FROM` буцаах бөгөөд эрэмбээр хамгийн түрүүнд шалгагдана. |
| **to** | Хүчинтэй, from-оос өөр | `A002` | `[property TO_OK]` `[IF FROM_OK]` | from хүчинтэй үед л to-гийн шалгалтад хүрнэ. |
| | Байхгүй | `X999` | `[ERROR]` | Үргэлж `ERROR_NO_TO` буцаана. |
| | from-той ижил | `A001` | `[ERROR]` | Үргэлж `ERROR_SAME_ACCOUNT` буцаана. |
| | Царцаагдсан to | `A003` | `[SINGLE]` | Тодорхойлолтод заагаагүй тул зан төлөвийг нэг тестээр баримтжуулахад хангалттай. |
| **amount** | Сөрөг | `-50` | `[ERROR]` | `ERROR_BAD_AMOUNT`. |
| | Тэг (хил) | `0` | `[ERROR]` | `ERROR_BAD_AMOUNT`-ийн хил дээрх утга. |
| | Хамгийн бага эерэг (хил) | `0.01` | `[SINGLE]` | `> 0` хилийн хүчинтэй тал; валют, лимиттэй хослуулах шаардлагагүй. |
| | Ердийн: `0 < a < L` | `100` | `[property AMT_OK]` `[IF TO_OK]` | Амжилттай замын үндсэн утга тул валют, лимитийн төлөвтэй хослоно. |
| | `a = L` (хил) | `500` | `[SINGLE]` | Лимитийн хилийн хүчинтэй тал (`201 OK`). |
| | `L < a ≤ B` | `600` | `[ERROR]` | Үлдэгдэл хүрэлцэх ч `ERROR_LIMIT`. |
| | `a = B` (хил) | `1000` | `[ERROR]` | Үлдэгдлийн хил; `L < B` тул `ERROR_LIMIT`. |
| | `a > B` | `1000.01` | `[ERROR]` | `ERROR_INSUFFICIENT` (лимит ч хэтэрсэн ч эрэмбээр үлдэгдэл түрүүлнэ). |
| | Хөрвүүлэхээс өмнө `≤ L`, дараа нь `> L` | `460 EUR` (= 506 USD) | `[ERROR]` `[IF CONV]` | Хөрвүүлэлттэй валют дээр л утга учиртай бөгөөд `ERROR_LIMIT` буцаана. |
| **currency** | Дансны валюттай ижил | `USD` | `[property SAME]` | Хөрвүүлэлтгүй үндсэн зам. |
| | Өөр (тоо нь томордог) | `MNT` | `[property CONV]` | Хөрвүүлэлт хийгдэх тул хэвийн утгатай хослоно. |
| | Өөр (тоо нь жижигрэх) | `EUR` | `[property CONV]` | 1-ээс их ханштай хөрвүүлэлт хийгдэх тул хэвийн утгатай хослоно. |
| **Орчин: өдрийн лимит** | Хоосон | 0 USD ашигласан | `[property LIM_FREE]` | Хэвийн утга. |
| | Хагас дүүрсэн | 300 USD ашигласан | `[property LIM_FREE]` | Өмнөх гүйлгээ тооцогдож буйг шалгах хэвийн утга. |
| | Бүрэн дүүрсэн | 500 USD ашигласан | `[ERROR]` | Ямар ч эерэг дүнд `ERROR_LIMIT`. |
| **Орчин: from үлдэгдэл** | Эерэг | 1000 USD | `[property BAL_OK]` | Хэвийн утга. |
| | Тэг | 0 USD | `[ERROR]` | Ямар ч эерэг дүнд `ERROR_INSUFFICIENT`. |

Тодорхойлолтод алдааны код заагаагүй тул үл мэдэгдэх валют (`XYZ`)-ийг тооцоонд оруулаагүй.

#### Тестийн тоо: N → M

**Бүрэн олонлог (бүх сонголтын үржвэр):**

| from | to | amount | currency | лимит | үлдэгдэл | |
|---|---|---|---|---|---|---|
| 3 | 4 | 9 | 3 | 3 | 2 | **= 1944** |

`3 × 4 × 9 × 3 × 3 × 2 = 1944`

**Хязгаарлалтын дараа:**

| Төрөл | Тоо | Тайлбар |
|---|---|---|
| `[ERROR]` | 12 | from 2 + to 2 + amount 6 + лимит 1 + үлдэгдэл 1, тус бүр нэг тест |
| `[SINGLE]` | 3 | to царцаагдсан, amount `0.01`, amount `= L` |
| Хэвийн хослол | 6 | from 1 × to 1 × amount 1 × currency 3 × лимит 2 × үлдэгдэл 1 |
| **Нийт** | **21** | |

**1944 → 21**
